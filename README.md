# Fashion Designer Agent

A design studio for turning a brand's reference images into new clothing designs.

- **Gallery** — upload or scrape reference looks into collections, with auto and manual annotations
- **Projects** — run a collection through a staged design process:
  1. **Concept** — explore directions from prompts, style tags, PDF mood boards and reference strength
  2. **Design** — refine shortlisted looks individually with detailed prompts
  3. **Realistic** — produce photorealistic model/product shots
  4. **Mood Board** — export a PDF of the full collection
- **Master prompt** — each project carries a theme that guides every generation
